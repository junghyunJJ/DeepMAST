# DeepMAST Architecture — Methods Content

## Multi-agent system design

DeepMAST is implemented as a hierarchical multi-agent system using the LangGraph framework (LangChain). The architecture comprises four layers: a workflow layer containing specialized agents, a capability layer providing skills-guided reasoning and tool interfaces, a resource layer supplying biological databases and computational engines, and human-in-the-loop (HITL) checkpoints ensuring user oversight at critical decision points (Figure 1).

## Supervisor agent and orchestration

A Supervisor Agent coordinates the end-to-end workflow through three sequential phases: pipeline construction, pipeline execution, and deep interpretation. Each phase transition is gated by an HITL approval node implemented via LangGraph's `interrupt()` mechanism, allowing users to approve, modify, or skip individual phases. The Supervisor maintains shared state (ST platform, disease context, species, sample count) across all child agents and supports skip-ahead routing for users who bring pre-computed analysis results.

## Pipeline Builder

The Pipeline Builder agent (STPipelineBuilderAgent) collects essential study metadata through structured HITL interactions: the spatial transcriptomics platform (Visium, MERFISH, Xenium, Slide-seq, etc.), disease or phenotype, species (human or mouse), sample count, and computational environment. Based on the platform type (spot-based or single-cell resolution), it designs a PipelineConfig specifying normalization (e.g., log, SCTransform, Pearson residuals), cell-type analysis (deconvolution for spot-based platforms or annotation for single-cell), and spatial clustering methods (e.g., Leiden, Louvain, BayesSpace).

## Pipeline Executor

The Pipeline Executor agent (PipelineExecutorAgent) implements a two-phase, nine-node graph architecture. Phase 1 (Preparation) loads the pipeline configuration, collects the h5ad input file path via HITL, resolves single-cell reference datasets for spot-based deconvolution (using CellxGene Census search or user-provided references ranked by a Visium reference selector MCP), and validates data integrity. Phase 2 (Execution) dynamically resolves MCP server configurations for each pipeline step, generates missing MCP servers on-the-fly via code-to-MCP conversion (Python via FastMCP or R via rmcpagent), and executes the full pipeline through a single ReAct agent with cascading h5ad outputs between steps.

## Deep Biological Interpreter

The Deep Biological Interpreter employs the DeepAgents framework with a wrapper agent pattern. The wrapper agent (DeepInterpreterWrapperAgent, 11-node graph) first executes spatial analysis steps 1-8 (clustering, neighborhood analysis, pathway enrichment, cell-cell interaction analysis) via the st_workbench_mcp server, then conducts an HITL research discussion for cluster, cell-type, and NMF factor selection, followed by targeted analysis steps 9-11. Subsequently, the wrapper invokes the Deep Interpreter agent, which coordinates four specialized subagents: (1) the **Planner** confirms analysis targets and produces an interpretation guide; (2) the **Searcher** extracts biological context and performs literature search via PubMed with automatic fallback strategies; (3) the **Interpreter** generates three-part biological interpretation with inline claim-level citation validation and quality-gated refinement (threshold >= 0.8, max 3 iterations); and (4) the **Reporter** synthesizes cross-part findings into a comprehensive HTML report. A SkillsMiddleware injects domain-specific search strategies (e.g., biomedical literature search, academic search) into agent prompts via progressive disclosure.

## Deep Drug Target Discovery

The Drug Target Discovery agent also uses the DeepAgents framework with four specialized subagents operating on the top-30 prioritized ligand-receptor (L-R) pairs from CCI analysis. (1) The **Evidence Assessor** executes a two-stage funnel: Stage 2 performs batch validation and scoring across OpenTargets, GWAS Catalog, and Ensembl VEP for all unique gene symbols against an eight-criterion rubric, followed by FEATURED gene selection (combined score >= 10); Stage 1 then enriches FEATURED L-R pairs with biological context via CellxGene Census co-expression, KEGG/Reactome pathway analysis, and STRING protein-protein interactions. (2) The **Deep Diver** conducts Stage 3 deep investigation of FEATURED genes, querying ChEMBL for drug profiles and existing compound data, and PubMed for supporting literature evidence. A zero-candidate short-circuit path bypasses this stage and hypothesis generation when no genes pass the FEATURED threshold. (3) The **Hypothesis Writer** generates four to six mechanistic hypotheses scored by an Upper Confidence Bound (UCB) algorithm balancing evidence strength, specificity, novelty, and actionability. (4) The **summarizer** compiles a publication-quality therapeutic target assessment report (drug.md) with iterative anti-hallucination validation. Three middleware guards (WriteFileArgGuard, ReadFileBlock, SubagentErrorGuard) protect against file I/O misuse and subagent recursion failures.

## Skills and SkillActivationBooster

Domain-specific skills are organized as structured markdown documents (SKILL.md) in two functional categories: (i) report and hypothesis generation skills (drug-target-reporting, drug-target-hypothesis, html-report-generator) that enforce programmatic score injection and anti-hallucination validation during output generation; and (ii) database query strategy skills (opentargets-database, gwas-database, chembl-database, string-database, cellxgene-census) that guide agents in constructing correct API queries. Rather than including all domain knowledge in agent prompts, DeepMAST employs a progressive disclosure pattern: the SkillsMiddleware injects a concise skill index into the system prompt, and agents read full skill documents on demand. In a controlled CCI interpretation ablation benchmark (600 trials across 4 conditions, Kruskal-Wallis p < 10^-42), guide-compliant structured skills reduced fabrication count by 54% (3.89 → 1.78 per response) and improved composite quality score from 3.14 to 3.89 compared to no-skill baselines. To further improve activation reliability, we developed the SkillActivationBooster, a structured two-phase evaluation protocol (Quick Screen → Evaluate → Implement) that replaces passive skill listing with explicit task-skill relevance reasoning before execution. In a separate benchmark (140 prompts, 420 paired binary skill decisions), SkillActivationBooster improved skill activation F1 from 81.7% to 93.9% (+12.2 percentage points; McNemar's test, p < 0.001), driven by a recall gain from 70.8% to 90.0% while maintaining 98.2% precision.

## MCP tool interface

All computational tools are exposed through the Model Context Protocol (MCP), providing a standardized interface between agents and resources. We developed three key MCP components. (1) **STworkbench MCP**, a custom FastMCP server providing a comprehensive suite of spatial transcriptomics analysis tools — spatial clustering visualization, cell-type composition, neighborhood enrichment (Squidpy), pathway enrichment (decoupler), spatial relationship modeling (MISTy), and LIANA-based cell-cell interaction analysis with NMF decomposition. (2) A **dynamic literature search pipeline** combining three complementary MCP layers: BioMCP provides biomedical API access (gene information, drug data, variant queries, clinical trials, and article search) as the external data source; search_literature_dynamic performs LLM-powered iterative query generation with coverage-driven gap filling (gene alias expansion via BioMCP, SJR-based journal quality ranking, multi-iteration convergence until gene/pathway coverage targets are met); and the **LangConnectRAG MCP** provides an adaptive, agentic RAG backend — a retrieve-grade-route loop where retrieved documents from the vector store are scored for relevance by an LLM judge, routed to either answer generation or LLM-driven query rewriting for re-retrieval, with hallucination detection on generated answers and on-demand corpus expansion (PubMed search, full-text download, and vector store indexing). (3) **RmcpAgent**, an agentic R-package-to-MCP converter that automatically wraps R bioinformatics packages (e.g., CARD) into MCP servers with validated function signatures and data quality checks. The Pipeline Executor can also dynamically generate new MCP servers on-the-fly when a user-selected analysis method lacks a pre-configured server.
