**Figure 1. Overview of the DeepMAST multi-agent architecture.** DeepMAST is a layered multi-agent system built on LangGraph that translates spatial transcriptomics (ST) data and user-defined biological questions into interpretable findings, therapeutic target evidence, and publication-quality reports. The architecture is organized into four layers. **(Top) Workflow Layer.** A Supervisor Agent orchestrates three sequential phases with human-in-the-loop (HITL) approval gates at each transition. (i) The **Pipeline Builder** collects study metadata (ST platform, disease, species, sample count) through structured HITL interactions and designs an analysis configuration. (ii) The **Pipeline Executor** runs the configured ST analysis pipeline via dynamically resolved MCP servers, with on-the-fly MCP generation for unsupported methods. (iii) Two **Deep Agents**, implemented using the DeepAgents framework, operate on prioritized ligand-receptor (L-R) candidates: the **Deep Biological Interpreter** (4 subagents: Planner, Searcher, Interpreter, Reporter) performs literature-grounded interpretation with claim-level citation validation and quality-gated refinement; the **Deep Drug Target Discovery** agent (4 subagents: Evidence Assessor, Deep Diver, Hypothesis Writer, summarizer) executes a staged funnel from multi-database evidence scoring through mechanistic hypothesis generation with UCB ranking. **(Middle) Capability Layer.** Domain-specific **Skills** in two categories — report/hypothesis generation (drug-target-reporting, drug-target-hypothesis, html-report-generator) and database query strategies (OpenTargets, GWAS, ChEMBL, STRING, CellxGene Census) — are injected via progressive disclosure through a SkillsMiddleware. In a CCI interpretation ablation benchmark (600 trials, 4 conditions), guide-compliant skills reduced fabrication by 54% and improved composite quality (Kruskal-Wallis p < 10^-42). The **SkillActivationBooster** protocol further improves activation F1 from 81.7% to 93.9% over passive listing (McNemar's test, p < 0.001). The **MCP Protocol** provides a standardized tool-calling interface. **(Bottom) Resource Layer.** Three key MCP components: (1) **STworkbench MCP**, a custom FastMCP server for spatial clustering, neighborhood enrichment (Squidpy), pathway enrichment (decoupler), spatial relationship modeling (MISTy), and LIANA-based CCI analysis with NMF; (2) a **dynamic literature search pipeline** combining BioMCP (article-search), LLM-powered iterative query generation (search-literature-dynamic with gene alias expansion, SJR journal ranking, coverage-driven gap filling), and the **LangConnectRAG MCP** (adaptive retrieve-grade-route loops with hallucination detection and on-demand corpus expansion); (3) **RmcpAgent**, an agentic R-package-to-MCP converter for wrapping R bioinformatics packages (e.g., CARD). Biological databases (OpenTargets, GWAS Catalog, ChEMBL, STRING, CellxGene Census, Ensembl VEP) supply the knowledge resources.
