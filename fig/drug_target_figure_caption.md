# Drug Target Assessment Agent — Figure Caption

**Figure X. Drug Target Assessment Agent architecture.** The agent employs a four-subagent pipeline to evaluate therapeutic target candidates from spatial transcriptomics cell-cell interaction (CCI) analysis. **(1)** The Evidence Assessor queries OpenTargets, GWAS Catalog, and Ensembl VEP to score all candidate genes against an 8-criterion rubric, then validates FEATURED genes (combined score >= 10) via STRING protein-protein interactions and CellxGene Census co-expression analysis. **(2)** The Deep Diver retrieves drug profiles from ChEMBL and literature evidence from PubMed for each FEATURED gene. **(3)** The Hypothesis Writer generates 4-6 mechanistic hypotheses scored by a UCB (Upper Confidence Bound) algorithm balancing evidence strength, specificity, novelty, and actionability. **(4)** The Report Writer compiles a publication-quality assessment using a pre-computed Reference Card as the single source of truth, with iterative anti-hallucination validation (fabricated PMID detection, classification verification, score integrity checks). Left panels show representative inputs at each stage; right panels show corresponding outputs. A zero-candidate short-circuit path (dashed arrow) bypasses the Deep Diver and Hypothesis Writer when no genes pass the FEATURED threshold. Three middleware guards protect against file I/O misuse, type coercion errors, and subagent recursion failures. Data shown from a breast cancer case study with 30 candidate ligand-receptor pairs.
