# 4. Gap Analysis

No Phase 3 IPF-specific EGFR inhibitor trial has been completed. TGF-beta pathway pleiotropic
effects require monitoring. Larger validation datasets needed.

---

# 5. Therapeutic Recommendations

- **EGFR**: Initiate Phase 2b/3 IPF trial of gefitinib.
- **TGFB1**: Continue fresolimumab Phase 2 with extended safety arm.
