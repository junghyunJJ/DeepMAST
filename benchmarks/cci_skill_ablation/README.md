# CCI Skill Ablation Benchmark

This bundle contains the reproducible artifacts for the DeepMAST CCI skill-ablation benchmark. The benchmark tests whether structured skill-style guidance reduces hallucination in free-text biological interpretations of spatial transcriptomics ligand-receptor pairs.

The primary reproducibility target is offline artifact regeneration from committed judged trial outputs. A live rerun wrapper is included for audit use when API credentials and model access are available.

## What Is Included

- `inputs/cci_full_cases.json`: 30 ligand-receptor benchmark cases.
- `inputs/pilot_cci_cases.json`: small pilot case set for smoke checks.
- `inputs/interest_sig_liana.csv`: source LIANA table used to derive the case set.
- `scripts/benchmark_cci_core.py`: prompt variants, judging rubric, scoring, and statistics.
- `scripts/run_cci_skill_ablation.py`: live generation + dual-judge runner.
- `results/full_cci_v2_D_guide_trials.jsonl`: committed judged trials for the 4-condition benchmark.
- `results/full_cci_v2_D_guide_summary.json`: reference summary regenerated by the offline path.
- `results/full_cci_v2_D_guide_results.md`: reference markdown results.
- `figures/`: reference main and supplementary figures.
- `metadata/source_paths.md`: source locations used to assemble this public bundle.

## Quick Start

From the repository root:

```bash
SKIP_R=1 bash benchmarks/cci_skill_ablation/scripts/reproduce_offline.sh
```

This regenerates:

```text
benchmarks/cci_skill_ablation/results/full_cci_v2_D_guide_summary.json
benchmarks/cci_skill_ablation/results/full_cci_v2_D_guide_results.md
benchmarks/cci_skill_ablation/results/figure_tables/
```

The Python-only offline path requires `scipy` for Kruskal-Wallis and Mann-Whitney tests. If `scipy` is unavailable, the summary still renders but inferential statistics are omitted.

To regenerate figures as well:

```bash
bash benchmarks/cci_skill_ablation/scripts/reproduce_offline.sh
```

Figure regeneration requires R packages `tidyverse` and `patchwork`; SVG output may also require `svglite`.

## Optional Live Rerun

The live rerun calls the generator model for every case, condition, and repeat, then judges each output with the configured judge models. It is intentionally preview-only by default.

Preview the command:

```bash
bash benchmarks/cci_skill_ablation/scripts/reproduce_live.sh
```

Run it:

```bash
OPENAI_API_KEY=... ANTHROPIC_API_KEY=... \
  bash benchmarks/cci_skill_ablation/scripts/reproduce_live.sh --run
```

Default live configuration:

- Generator: `openai:gpt-5.4-nano`
- Repeats: `5`
- Judges: `openai:gpt-5.4,claude:claude-sonnet-4-20250514`
- Output: `benchmarks/cci_skill_ablation/live_runs/<RUN_ID>/results/`

Override configuration with environment variables:

```bash
CCI_BENCHMARK_MODELS=openai:gpt-5.4-nano \
CCI_BENCHMARK_REPEATS=1 \
CCI_JUDGE_MODELS=openai:gpt-5.4 \
RUN_ID=smoke \
  bash benchmarks/cci_skill_ablation/scripts/reproduce_live.sh --run --cases benchmarks/cci_skill_ablation/inputs/pilot_cci_cases.json
```

Live outputs may vary with model version, provider behavior, credentials, and package versions. Use the committed offline artifacts as the stable reference result.

## Main Result

The benchmark compares four prompt conditions:

- `A_no_skill` / No Skills: base interpretation prompt only.
- `B_unstructured_prose` / Unstructured Prose: hallucination-prevention content in prose.
- `C_structured_skill` / Basic Structured SKILLs: same content as B, structured as markdown rules and tables.
- `D_guide_compliant_skill` / Guide-Compliant Structured SKILLs: C plus examples, traps, motivation, and self-checks.

The reference 4-condition result is in:

```text
results/full_cci_v2_D_guide_results.md
results/INTERPRETATION.md
```

In brief, hallucination scores improve from no guidance to prose guidance, improve again when the same content is rendered as Basic Structured SKILLs, and show a smaller non-significant trend from Basic Structured SKILLs to Guide-Compliant Structured SKILLs.
