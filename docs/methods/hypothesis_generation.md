# Hypothesis Generation

## Literature-Grounded Hypothesis Generation

The DeepMAST framework employed a systematic hypothesis generation workflow adapted from HypoGeniC (Zhou et al., 2024) and HypoRefine (Liu et al., 2024) for spatial transcriptomics cell-cell interaction analysis. The PLANNER subagent first read the target configuration file specifying the analysis mode, target clusters or cell types, and data directory path. Subsequently, up to eleven distinct analysis results were loaded across three analytical Parts: Part 1 encompassed spatial clustering, cell type composition, neighborhood enrichment, Decoupler pathway activity, and MISTy spatial modeling; Part 2 included LIANA Moran's I autocorrelation, NMF factor analysis, pathway-factor associations, and cell-type-specific spatially variable genes (ctSVG); Part 3 contained spatial ligand-receptor analysis and ligand-receptor interaction summaries.

Following data ingestion, the workflow performed literature initialization by querying PubMed via the NCBI E-utilities API to retrieve ten foundational papers. Search queries combined disease context terms (inferred from cell type composition profiles) with spatial transcriptomics methodology terms to ground hypotheses in established biological knowledge prior to generation. The system then generated four to six initial hypotheses distributed across four thematic categories: spatial organization patterns (Part 1 analyses), cell-cell communication mechanisms (Part 2 analyses), pathway activation states (Parts 1-2 integration), and novel integrative hypotheses spanning multiple analytical Parts. Each hypothesis was required to include a falsifiable prediction, explicit references to supporting analyses, key biological entities (cell types, pathways, ligand-receptor pairs), and literature citations from the initialization step.

To ensure comprehensive coverage of all analytical results, a gap detection step identified "orphan analyses" not referenced by any existing hypothesis. For each uncovered analysis, one to two additional hypotheses were generated to eliminate coverage gaps. All hypotheses were subsequently evaluated using a four-dimensional scoring function adapted from the Upper Confidence Bound (UCB) framework. The composite score was calculated as: Score = 0.30 × Evidence_Coverage + 0.30 × Specificity + 0.20 × Literature_Grounding + 0.20 × Novelty, where Evidence_Coverage quantified the fraction of eleven total analyses referenced (scaled as min(analyses_referenced / 4, 1.0)), Specificity assessed the precision and falsifiability of predictions (scored 0.0 for vague statements, 0.5 for directional named-entity predictions, 1.0 for quantitative falsifiable claims), Literature_Grounding evaluated alignment with Step 3 papers (0.0 for no support, 0.5 for partial support in different contexts, 1.0 for strong disease-matched support), and Novelty measured discovery potential beyond established biology (0.0 for textbook restating, 0.5 for known mechanisms in novel contexts, 1.0 for testable new mechanisms). Hypotheses scoring below 0.4 were removed, yielding a final set of three to five high-quality hypotheses. The structured reflection process for gap analysis and scoring was implemented using a dedicated reasoning tool to ensure systematic evaluation. The final output was written as a strategic plan document containing ranked hypotheses, dimensional scores, composite scores, supporting analyses, and literature references to guide downstream interpretation agents.
